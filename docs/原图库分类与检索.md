原图统一保留在 `SourceAssets/pvz2/images/`，原索引为 `SourceAssets/pvz2/image_index.csv`。分类清单放在 `SourceAssets/pvz2/images_by_category/`；按用户选择，分类目录不再保存图片副本，也不改动现有工程引用。

分类优先使用原始 source 目录：植物和僵尸按实际角色目录分类，特效不因共享植物图集而改归植物，NPC 不因名字带僵尸/世界词汇而改归战斗角色。图集根据其中拆件的多数类别归属；单一角色图集继承角色名，共享图集保留完整 atlas 来源字段。

## 文件与检索

- `image_catalog.csv`：全量清单。
- 各分类下的 `分类清单.csv`：该类别清单。
- `unclassified.csv`：新增命名未识别时的队列；当前只有表头。
- `分类统计.txt`：数量统计。

清单保留 `category`、`character`、`subcategory`、`type`、`resolution`、`filename`、`original_path`、`source`、`resource_id`、`atlas`、`width`、`height`。`original_path` 相对仓库根，直接指向原图库图片。

```powershell
python -X utf8 Tools/classify_source_images.py --query peashooter --limit 10
python -X utf8 Tools/classify_source_images.py --category 植物 --character peashooter --resolution 1536
python -X utf8 Tools/classify_source_images.py --category 道具与NPC --query crazydave
```

查询同时匹配角色、子类、文件名、资源 ID、原路径和 atlas；先给出匹配总数，默认显示前 50 条，`--limit` 调整显示数量。角色分组名使用原路径英文名，如 `peashooter`、`zombie_roman_zomboss`。

重建分类清单：

```powershell
python -X utf8 Tools/classify_source_images.py
```

重建只读取原图片和索引，写入分类 CSV/统计，不复制、搬移或删除原图。

## GitHub 共享

全量分类清单以 `reference/image-library/image_catalog.csv.gz` 压缩入库，统计和哈希见同目录 `summary.json`。查询工具优先读取本地清单；本地清单不存在时自动读取共享压缩清单，其他成员克隆后可直接检索全部 87,653 条记录。`original_path` 仍指向原图库，查看图片需要本地原图；完整 SourceAssets 未上传。

本地重建后运行 `python -X utf8 Tools/classify_source_images.py --share-catalog` 更新共享清单。此命令只压缩清单，不复制图片。
