僵尸覆盖普通、路障、铁桶、旗帜、小鬼、巨人、报纸，以及埃及、海盗、狂野西部、未来、黑暗时代、冰河、失落之城、摇滚、恐龙、海滩等世界的基础和特殊敌人。路障、铁桶通常共用基础身体：身体描述为 `actors/zombies/BasicZOMBIE.json`，护甲分别为 `actors/armors/BasicConeARMOR.json`、`BasicBucketARMOR.json`；原始护甲 armature、受损动作和 PNG 已保留。

原生 PAM 的植物是：豌豆射手、向日葵、坚果、食人花、阳光菇、芦荟和龙葵；僵尸是雪豌豆僵尸、冰河鼬鼠僵尸。其余常见角色主要由批量 DragonBones 数据覆盖。来源文件名如 `ALOE_HEAL_EFFECT`、`SPORESHROOM_PROJECTILE` 保留原样，具体内容以解码出的图片引用和动作清单为准。

## 给 AI 的查询入口

从仓库根运行：

```powershell
python -X utf8 Tools/animation_library.py --query 向日葵
python -X utf8 Tools/animation_library.py --query BasicCone --format dragonbones
python -X utf8 Tools/animation_library.py --query Chomper --format pam
```

支持中文名、英文名、来源 codename、Prefab/armature/文件名；输出实际骨架、图集、图片、动作、PAM 及其配图状态。`--details` 包含完整来源和逐图哈希；不加查询参数显示统计。

机器总索引是 `reference/pam-resources/animation-library.json`。`characters` 将来源 ID 和中英文名映射到 `entries[].id`；DragonBones 的 `descriptor` 保留原 Prefab 组合，`rigs[]` 给出骨架、图集、图片、armature 与动作；`native_pams[]` 按哈希去重并保存原生来源、动作和 `textures.status`。

`armatures` 还索引骨架文件内部的共用子 armature；例如 `--query wheelRolling --format dragonbones` 会返回其实际骨架、图集和纹理文件，可供组装复合角色时复用。

## 已完成的核验与缺口

- 所有取得的 PAM 均经现有 pam-viewer 0.1.1 WASM 解码；去重 13 个。配图验证使用同一工具，完整者缺图数为 0。
- 总索引重建检查 2447 个文件哈希、PNG 可读性及全部 369 对图集边界；来源目录的资源引用均存在。
- 官方 DragonBones core 已构建/采样 587 组 armature，覆盖所有 793 个条目。原数据的少量重复骨/槽及三个特殊敌人的子骨架提示保留在索引 warnings 中，详见批量来源 SOURCE.md；尚未逐个在 Godot 渲染验收。
- 本轮公开仓库和资源集合调查未取得覆盖全部常见角色的原生 PAM 完整包。阳光菇的原生配图仍缺 64 项，但已取得它的完整 DragonBones 骨架、图集和配图。

## 重现与扩展

```powershell
python -X utf8 Tools/export_actor_animation_library.py
node Tools/inspect_dragonbones_library.mjs --library reference/pam-resources/pvzge-actors-462f116/library.json --output reference/pam-resources/pvzge-actors-462f116/inspection.json
node Tools/inspect_pam_library.mjs --input-list reference/pam-resources/native-pam-paths.json --output reference/pam-resources/native-pam-inspection.json
python -X utf8 Tools/prepare_native_animation_images.py
python -X utf8 Tools/animation_library.py --rebuild
```

批量原生导出需要本地固定 PVZGE 构建、Playwright 和 Edge；获取方法见资源与工具文档。PAM 配图准备复用已有映射/裁片工具，部分文件需要本机 `SourceAssets/pvz2/` 原图库。已取得的文件与索引可直接查用，普通查找无需重新导出。
